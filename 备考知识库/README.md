## 四、四类知识点 ↔ 考试题型映射（规划的发动机）

掌握路径对每类知识点用**不同的过关方式 + 硬门槛**：

| 类型 | 对应考点 | 过关方式 | 门槛 |
|---|---|---|---|
| `memory` 记忆 | 常识、公基法条、公文格式、文化素养、专业名词 | 选择题 | 量化 **≥0.9** |
| `procedure` 步骤 | 行测速算、解题步骤、公文结构、教学设计流程、SQL | 选择题/简答 | 量化 **≥0.9** |
| `concept` 理解 | 言语主旨、逻辑命题、教育心理理论、通信概念 | 费曼讲解 | 质性通过 |
| `design` 产出 | 申论大作文、教资教案、教学设计 | 产出+讲解，AI 批改 | 质性通过 |

要点：
- 量化门槛 0.9 = 必须连续做对才能推进，单次蒙对不算数（源码单次答对只给 0.5 掌握度）。
- 间隔重复内建：已掌握知识点按遗忘曲线排期复习，治「常识/法条背了就忘」。
- `design` 类无法机改，靠 AI 质性评判（`mastery_assess`）。

## 五、落地命令

> 🔧 **一键批量建 8 个库**：`bash 建库.sh [资料根目录]`（默认 `~/备考资料`，幂等可重跑）。有资料的库直接建，没资料的自动建占位目录。下面单条命令供手动/追加用。

```bash
cd ~/www/DeepTutor && source .venv/bin/activate

# ① 一键批量建库（推荐）
bash 备考知识库/建库.sh

# ①' 手动单库建（材料层，有资料就建，没资料先跳过；掌握路径不依赖 KB 也能先建）
deeptutor kb create 行测 --docs-dir ~/备考资料/行测
deeptutor kb create 申论 --docs-dir ~/备考资料/申论
deeptutor kb create 公基 --docs-dir ~/备考资料/公基
deeptutor kb create 教资-综合素质 --docs-dir ~/备考资料/教资/综合素质
deeptutor kb create 教资-教育知识 --docs-dir ~/备考资料/教资/教育知识
deeptutor kb create 教资-信息技术学科 --docs-dir ~/备考资料/教资/信息技术学科
deeptutor kb create 国企-计算机专业 --docs-dir ~/备考资料/国企专业
# 后续追加：deeptutor kb add 行测 --docs-dir ~/新资料

# ② 一键批量建 7 条掌握路径（推荐）
bash 备考知识库/一键建路径.sh --web --open   # 打印+浏览器打开 7 条稳定直达 URL
bash 备考知识库/一键建路径.sh --cli           # 真正一键：批量跑 deeptutor 建路径
bash 备考知识库/一键建路径.sh --resume        # 打印已建路径的恢复命令

# ②' 手动网页方式（路径 id 必须用 ASCII，见下方坑）
# 打开：http://127.0.0.1:3782/home?capability=mastery_path&mastery_path_id=xingce
# 进去粘贴「一键建路径.sh --web」打印的那行提示词即可

# ③ 单条命令行方式（session 用 --resume 查到的 id）
deeptutor run mastery_path "继续学习" --kb 行测 -l zh --session <session-id>
deeptutor run deep_question "出5道资料分析题，含答案" -t rag --kb 行测 -l zh
```

> ⚠️ 关键坑：
> 1. **必须从项目根目录运行**：DeepTutor 的数据目录（含模型配置 model_catalog.json）跟随「当前工作目录」。在别的目录跑 `deeptutor` 会加载一个空目录 → 落到默认 OpenAI 端点 → **401**。两个脚本已自动 `cd` 到项目根并设 `DEEPTUTOR_HOME`；手动跑命令务必先 `cd ~/www/DeepTutor`。
> 2. **路径 id 只认 ASCII**：`mastery_path_id`/`session_id` 用中文会被源码 `_sanitize_path_id` 塌缩成 `default`（`行测`→`default`、`教资-综合素质`→`-`）。务必用 ASCII id。
> 3. **命令行首跑生成随机 UUID**：`deeptutor run` 的 `--session 自定义名` 在会话不存在时会被丢弃、生成随机 UUID，恢复要用返回的 session id。网页 `mastery_path_id=` URL 才是稳定持久路径的正解；`一键建路径.sh --cli` 会自动记录映射。

> ASCII id 对照：行测=`xingce` 申论=`shenlun` 公基=`gongji` 教资-综合素质=`jiaozi-zonghe` 教资-教育知识=`jiaozi-jiaoyu` 教资-信息技术学科=`jiaozi-xueke` 国企-计算机专业=`guoqi-jisuanji`

## 六、JSON 怎么用（喂给 mastery_build）

每个 `掌握路径/*.json` 结构如下，其中 `modules` 数组直接对应 `mastery_build` 的 `modules` 参数：

```json
{
  "mastery_path_id": "xingce", // 仅占位说明，系统不用它；真实 id 由 URL/session 决定（必须 ASCII）
  "mode": "replace",           // 首次 replace，追加用 append
  "modules": [
    {"name": "数量关系", "knowledge_points": [{"name": "数学运算基础", "type": "memory"}]}
  ]
}
```

用法（三选一）：
1. **最省事**：跑 `bash 一键建路径.sh --web`，复制它打印的那行提示词（已内联 modules）粘贴到对话。
2. 或直接说「请用 `mastery_build`（mode=replace）建立以下模块：<粘贴整个 `modules` 数组>」。
3. 或跑 `bash 一键建路径.sh --cli` 全自动批量建。
