# 时政热点 & 错题本 维护清单

## 一、时政热点库（`时政热点` KB，每周滚动更新）

### 固定节奏
- **每周日**：追加过去 7 天凉山州 / 四川 / 全国时政，来源（政府网、四川日报、凉山发布等）。
- **招考季节点**（国考 10 月、省考 11 月、事业编 3 月/9 月）：额外追加「你能报的单位 + 截止时间」。

### 时政条目模板（每条一行，存成 Markdown 追加进 KB）

```markdown
# 2026-XX-XX 时政
- 领域：政治 / 经济 / 科技 / 民生 / 法律 / 凉山本地
- 事件：一句话概括
- 考点关联：对应公基「时政」/行测「常识判断」哪个知识点
- 可能出题角度：选择题怎么考
```

### 追加命令

```bash
cd ~/www/DeepTutor && source .venv/bin/activate
# 把新时政写进一个 md，再追加到库
deeptutor kb add 时政热点 --doc ~/备考资料/时政/2026-XX-XX.md
```

### 自查搜索式（可随时让 AI 重跑）
- 公务员：`2027 国考/四川省考 凉山州 计算机 通信工程 岗位`
- 事业编：`凉山州 事业单位 招聘 计算机 信息技术`
- 国企：`凉山州属国企 / 中国移动凉山 / 国网凉山 招聘`
- 高校：`西昌学院 / 西昌民族幼专 招聘 实训 信息中心 实验员`
- 教师编/特岗：`凉山州 中小学/中职 信息技术教师 招聘 特岗 计算机`

## 二、错题本（自动沉淀 + 手动补充）

### 自动沉淀（无需手动）
掌握路径里每次 `mastery_grade` 批改，都会**自动同步到题库（Question Bank）**，含题面、选项、你的作答、正误。这是天然的错题本。

### 手动补充模板（用 `write_note` 或 Notebook）

```markdown
# 错题记录
- 日期：
- 科目/路径：行测·数量关系 / 申论 / 公基·法律 …
- 原题：<粘贴题干>
- 我的错误答案：<你的作答>
- 正确答案：<答案>
- 错误原因归类：知识结构性 / 理解偏差 / 应用错误 / 元认知（粗心）
- 对应知识点：<掌握路径里的知识点名>
- 一句话教训：
```

### 每周复盘节奏
- **周日**：导出/翻看本周错题，挑「同一知识点错 ≥2 次」的，回掌握路径重刷该知识点（间隔重复会自动到期）。
- 申论/教资教案这类 `design` 错题：不是"对错"，是"评分点"，记录 AI 批改给的评分点缺口。
